PayPal Sandbox

Checking connection

Creates an order, opens PayPal for buyer approval, and captures the approved sandbox payment.

  1. Create a free PayPal Developer account.
  2. Create a sandbox REST app and personal buyer account.
  3. Copy .env.example to .env.
  4. Set PAYPAL_CLIENT_ID and PAYPAL_CLIENT_SECRET, then restart.

Ollama · Local AI

Checking local model…

A local model selects products and explains its choices. Relay validates every price and budget on the server.

  1. Install Ollama for your operating system.
  2. Run ollama pull llama3.2:3b.
  3. Keep Ollama running.
  4. Choose Local AI in the purchase planner.
